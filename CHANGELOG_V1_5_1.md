# Project Controls AI Suite v1.5.1

## Schedule Builder usability changes

- Added a **Remove all** button above the Generated / Editable Schedule activity table.
- Remove all is disabled when the activity table is empty.
- The action requires confirmation before clearing the generated activity set.
- Cleared activities are immediately persisted to the browser's local schedule-builder store.
- Removed the AI chat panel from beneath Schedule Builder; the wizard and editable activity table are now the complete builder workspace.
- Cache/version identifiers bumped to `v1.5.1` for GitHub Pages deployment.
